Privacy Policy

Дата публикации: 6 октября 2026 г.

1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки, хранения и защиты информации о физических лицах (далее — «Пользователи»), использующих мобильное приложение «BEER Liga Manager» (далее — «Приложение»).

1.2. Оператором обработки персональных данных является Разработчик приложения: Гольцов Алексей Евгеньевич (далее — «Оператор»).

1.3. Приложение представляет собой специализированный автономный хоккейный планшет и инструмент менеджмента команды, обеспечивающий ведение состава, статистику игроков, планирование упражнений, управление сменами и создание тактических схем.

1.4. Базовый принцип работы: Приложение работает полностью автономно. Данные сохраняются исключительно локально на вашем устройстве в защищённой базе данных. Оператор не собирает и не хранит личные данные игроков на сторонних серверах.

1.5. Установка и использование Приложения означают согласие Пользователя с условиями настоящей Политики.

2. Категории и объем данных

2.1. Данные, вводимые Пользователем локально:

  • Данные игроков и штаба: фамилия, имя, отчество (или псевдоним), игровой номер, амплуа (позиция), дата рождения (для формирования локальных напоминаний), физические метрики и показатели тестирования, посещаемость тренировок.
  • Данные команды: название команды, логотип, составы звеньев и пятерок, пользовательские тактические схемы и рисунки.
  • Игровые и финансовые заметки: статистика матчей, записи о командных взносах/оплатах (при ведении Пользователем).
  • Графические материалы: аватары игроков и изображения упражнений, выбранные из галереи устройства или созданные с помощью камеры.

2.2. Системные отчёты об ошибках (Crash Reports):

В случае сбоя может формироваться технический отчёт: модель устройства, версия ОС Android, версия Приложения и текстовый стектрейс ошибки (без включения персональных данных игроков).

Автоматическая отправка отчётов осуществляется только при включении опции в настройках Приложения. Пользователь также может отправить отчёт вручную (скопировав текст в буфер обмена для передачи в службу поддержки).

3. Разрешения устройства

Приложение запрашивает у операционной системы Android только те разрешения, которые необходимы для выполнения его функций:

  • CAMERA — исключительно для считывания QR-кодов при локальном P2P-связывании устройств и для создания аватаров игроков/фотографий упражнений. Не используется для скрытой съёмки.
  • BLUETOOTH_SCAN, BLUETOOTH_CONNECT, NEARBY_WIFI_DEVICES, ACCESS_FINE_LOCATION — требуются Android исключительно для обеспечения прямого обмена данными между устройствами тренеров поблизости (Google Nearby Connections / Wi-Fi Direct / Bluetooth). Данные о геопозиции не собираются и не передаются.
  • POST_NOTIFICATIONS — отображение локальных напоминаний о днях рождения игроков и статуса работы таймера смен во время матча.
  • VIBRATE, WAKE_LOCK, FOREGROUND_SERVICE — поддержание непрерывной работы секундомера и таймера смен во время тренировок и игр.

4. Цели обработки данных

  • Обеспечение функционирования всех модулей Приложения (составы, тактика, секундомер смен, статистика).
  • Отображение локальных уведомлений и напоминаний.
  • Обеспечение прямой передачи данных между устройствами Пользователей по их инициативе (P2P-обмен составами и схемами).
  • Улучшение стабильности работы Приложения на основе обезличенных отчётов об ошибках (при согласии Пользователя).

5. Хранение и уничтожение

5.1. Хранение: Данные хранятся во внутренней изолированной памяти устройства в локальной базе данных SQLite (Room) и настройках SharedPreferences.

5.2. Резервное копирование: Пользователь может настраивать локальное создание резервных копий (бэкапов) базы данных на своём устройстве.

5.3. Удаление данных: Любые записи редактируются и удаляются через интерфейс Приложения. Полное уничтожение всех данных происходит при удалении (деинсталляции) Приложения с устройства или очистке его данных в системных настройках Android.

6. Передача третьим лицам

Отсутствие сторонних трекеров: Приложение не содержит рекламных модулей и аналитических трекеров (Google Analytics, Firebase Analytics, Yandex AppMetrica и т.д.).

Передача данных возможна исключительно по личной инициативе Пользователя:

  • P2P-обмен: Составы и схемы могут передаваться напрямую на другое устройство тренера по локальной сети/Bluetooth при установлении соединения обеими сторонами.
  • Шеринг: Экспорт текстовых отчётов или изображений в сторонние приложения (мессенджеры, e-mail) через стандартное меню Android «Поделиться».

Оператор не продаёт и не передаёт персональные данные Пользователей третьим лицам.
