# ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ И ОБРАБОТКИ ПЕРСОНАЛЬНЫХ ДАННЫХ
**Мобильного приложения «BEERLIGA Hockey Manager»**

Дата публикации: 6 октября 2026 г.

---

### 1. ОБЩИЕ ПОЛОЖЕНИЯ

1.1. Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки, хранения и защиты информации о физических лицах (далее — «Пользователи»), использующих мобильное приложение **«BEER Liga Manager»** (далее — «Приложение»).

1.2. Оператором обработки персональных данных является Разработчик приложения: **Гольцов Алексей Евгеньевич** (далее — «Оператор»).

1.3. Приложение представляет собой специализированный автономный хоккейный планшет и инструмент менеджмента команды, обеспечивающий ведение состава, статистику игроков, планирование упражнений, управление сменами и создание тактических схем.

1.4. **Базовый принцип работы Приложения:** Приложение работает автономно. Основной массив данных, вводимых Пользователем, сохраняется **исключительно локально на устройстве Пользователя** в защищённой базе данных Приложения. Оператор не осуществляет систематический сбор или хранение персональных данных Пользователей на собственных серверах.

1.5. Установка и использование Приложения означают согласие Пользователя с условиями настоящей Политики.

### 2. КАТЕГОРИИ И ОБЪЕМ ОБРАБАТЫВАЕМЫХ ДАННЫХ

2.1. **Данные, вводимые Пользователем локально в Приложение:**
* **Данные игроков и тренерского штаба:** фамилия, имя, отчество (или псевдоним), игровой номер, амплуа (позиция), дата рождения (для формирования локальных напоминаний), физические метрики и показатели тестирования, посещаемость тренировок;
* **Данные команды:** название команды, логотип, составы звеньев и пятерок, пользовательские тактические схемы и рисунки;
* **Игровые и финансовые заметки:** статистика матчей, записи о командных взносах/оплатах (при ведении Пользователем);
* **Графические материалы:** аватары игроков и изображения упражнений, выбранные из галереи устройства или созданные с помощью камеры.

2.2. **Технические данные и системные отчёты об ошибках (Crash Reports):**
* В случае возникновения сбоя в работе Приложения может формироваться технический отчёт, содержащий: модель устройства, версию операционной системы Android, версию Приложения и текстовый стектрейс ошибки (без включения персональных данных игроков).
* **Отправка отчётов:** Автоматическая отправка отчётов осуществляется только при включении соответствующей опции в настройках Приложения. Пользователь также может отправить отчёт вручную (скопировав текст в буфер обмена для передачи в службу поддержки).

### 3. ИСПОЛЬЗОВАНИЕ РАЗРЕШЕНИЙ УСТРОЙСТВА

Приложение запрашивает у операционной системы Android только те разрешения, которые необходимы для выполнения его функций:

3.1. **Камера (`CAMERA`):** Используется исключительно для считывания QR-кодов при локальном P2P-связывании устройств и для создания аватаров игроков/фотографий упражнений. Камера не используется для скрытой съёмки.
3.2. **Беспроводные модули и геопозиция (`BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT`, `NEARBY_WIFI_DEVICES`, `ACCESS_FINE_LOCATION`):** Требуются операционной системой Android исключительно для обеспечения работы функции прямого обмена данными между устройствами тренеров поблизости (технология Google Nearby Connections / Wi-Fi Direct / Bluetooth). Данные о местоположении Оператором не собираются и не передаются.
3.3. **Уведомления (`POST_NOTIFICATIONS`):** Используются для отображения локальных напоминаний о днях рождения игроков и статуса работы таймера смен во время матча.
3.4. **Вибрация и режим работы экрана (`VIBRATE`, `WAKE_LOCK`, `FOREGROUND_SERVICE`):** Используются для работы секундомера/таймера смен во время тренировочного и игрового процесса.

### 4. ЦЕЛИ ОБРАБОТКИ ДАННЫХ

4.1. Обработка данных осуществляется исключительно в целях:
* Обеспечения функционирования всех модулей Приложения (составы, тактика, секундомер смен, статистика);
* Отображения локальных уведомлений и напоминаний;
* Обеспечения прямой передачи данных между устройствами Пользователей по их инициативе (P2P-обмен составами и схемами);
* Улучшения стабильности работы Приложения на основе обезличенных отчётов об ошибках (при согласии Пользователя).

---

### 5. ЛОКАЛЬНОЕ ХРАНЕНИЕ, БЭКАПЫ И УНИЧТОЖЕНИЕ ДАННЫХ

5.1. **Хранение:** Данные хранятся в локальной базе данных SQLite (Room) и настройках `SharedPreferences` во внутренней изолированной памяти устройства Пользователя.
5.2. **Резервное копирование:** Пользователь может настраивать локальное создание резервных копий (бэкапов) базы данных на своём устройстве.
5.3. **Удаление данных:**
* Пользователь может в любой момент отредактировать или удалить любые записи (игроков, команды, схемы) через интерфейс Приложения.
* Полное уничтожение всех данных происходит при удалении (деинсталляции) Приложения с устройства или очистке данных Приложения в системных настройках Android.

---

### 6. ПЕРЕДАЧА ДАННЫХ ТРЕТЬИМ ЛИЦАМ И СТОРОННИЕ СЕРВИСЫ

6.1. **Отсутствие сторонних трекеров:** Приложение **не содержит** рекламных модулей и сторонних аналитических трекеров (Google Analytics, Firebase Analytics, Yandex AppMetrica и т.д.).
6.2. **Передача данных по инициативе Пользователя:**
* **P2P-обмен:** Составы и схемы могут передаваться напрямую на другое устройство тренера по локальной сети/Bluetooth при успешном установлении соединения обеими сторонами.
* **Шеринг:** Пользователь может экспортировать текстовые отчёты или изображения в сторонние приложения (мессенджеры, e-mail) через стандартное системное меню Android «Поделиться».
6.3. Оператор не продаёт и не передаёт персональные данные Пользователей третьим лицам.
